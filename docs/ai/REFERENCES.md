# AI 작업에 필요한 자료 안내

읽는 순서는 `AGENTS.md` → `docs/ai/HANDOFF.md` → 해당 코드 및 아래 참고 자료다. 최신 방향과 과거 기획을 구분한다.

| 자료 | 용도와 주의점 |
| --- | --- |
| [대회 분석](../competition/README.md) | 2026 C.O.D.E. 트랙 3 목적·요건·평가안. 당시 확보한 자료 기준이며 이후 공식 변경은 다시 확인 |
| [출처 목록](../competition/sources.md) | 공식 공고, 사용자 제공 가이드·전사문, 보관 파일의 출처와 한계 |
| [팩트체킹과 갈등 연구](../competition/fact-checking-and-conflict.md) | 사실 인식 개선과 갈등 감소의 차이, 혼합된 연구 결과. ScrollFact 효과의 입증 자료는 아님 |
| [11월 1일 코칭 기록](../competition/coaching-2026-11-01.md) | 원래 구상과 대회 연결에 대한 고민. 비교 시험안은 과거 검토안 |
| [코칭 데이터](../../frontend/src/coaching/brief.json) | 당시 웹 요약·PDF의 공통 콘텐츠 원본 |
| [축제 부스 참고 HTML](../references/festival-original.html) | 사용자 제공 데모의 사본. 현행 1단계보다 넓은 기능을 포함한 참고자료 |
| [백엔드 AI 연결](../../backend/ScrollFact/README.md) | 평가 어댑터 입력·출력 계약 및 미구현 범위 |
| [프론트 API 명세](../../frontend/docs/backend-api.md) | 실제 요청·상태·결과 계약. 최신 의견 중심 기능의 API가 아님 |
| [과거 캡처와 PDF](../../output/) | 각 실험 단계의 시각 자료. 현재 화면의 최신 스크린샷이라고 가정하지 말 것 |

`docs/competition/references/`에는 기존 프로젝트에서 보관하던 대회 PDF·가이드 이미지·발표 전사문을 포함한다. 전사문은 음성 인식 오류가 있는 참고자료이며 정확한 직접 인용이나 새로운 의무를 확정하는 근거로 사용하지 않는다.

`docs/references/festival-original.html`은 프로젝트 관련 채팅에 사용자가 첨부했던 ‘ScrollFact 축제 부스 시연 (Copy).html’을 내용 변경 없이 복사한 것이다. 별도의 실서비스로 배포한 것은 아니다.

관련 AI 대화에서 확인한 핵심 의사결정은 `HANDOFF.md`에 정리했다. 개인 Codex 홈 디렉터리, 계정 인증, 다른 프로젝트의 대화나 개인 메모리는 이 저장소의 인수인계 범위에 포함하지 않는다.
