정리일: 2026년 11월 1일. 대상은 ScrollFact가 준비하는 **트랙 3 상상 자유 아이디어 경연**이다. [심층 분석](README.md)은 아래 자료를 바탕으로 한다.

학술 근거는 [팩트체킹과 대인 갈등 심층 조사](fact-checking-and-conflict.md)에 별도로 정리했다. 연구별 측정 결과·방법·한계와 원문 링크를 포함하며, 대회 공식 요구와 제품 효과에 대한 가설을 구분한다.

## 자료를 적용하는 순서

현재 보유한 결선 전용 안내문의 구체적인 요건을 준비 기준으로 삼는다. 초기 모집 공고는 전체 맥락과 변경 이력에 사용한다. **이후 받은 공식 개별 안내가 있다면 해당 항목을 다시 대조해야 한다.** 결선 안내문 자체도 평가 기준을 최종 확정본이라고 표시하지 않는다.

발표자의 설명은 출제 의도를 이해하는 근거다. 발언을 새로운 의무나 배점으로 바꾸지 않는다. 심사위원의 예상 질문과 제품 설계 해석은 별도의 분석이며 공식 규칙이 아니다.

참가 대상은 공식 웹 공지에 전국 중·고등학생으로 표시되어 있다. 모집요강 수정본의 PDF 텍스트에는 수정 전 문구가 함께 추출되므로, 추출된 문자열만 보고 추가 참가 제한을 단정하지 않는다. 이번 분석은 이미 진행 중인 팀의 결선 준비에 초점을 둔다.

아래는 전사문의 **취지 요약**이다. 원문을 정확히 옮긴 직접 인용이 아니다.

전사문의 회사 소개, 업체별 모델 비교, 인지 발달 관련 주장 등은 대회 요건을 확정하는 근거로 사용하지 않았다. 강연자가 실제 결선 심사위원인지도 확인된 정보가 아니다.

## 아직 확보되지 않은 최신 정보

- 담당교사·팀장에게 전달된 결선 최신 제출 안내와 확정 평가표.
- 발표자료·백업 영상의 마감, 파일 규격, 전달 방법.
- 전시물 규격, 현장 장비·인터넷·설치 환경과 상세 시간표.
- 팀의 실제 멘토링 완료 내역과 인정 횟수.
- 복수 산출물의 제출 가능 여부, 심사 현장 임의 입력 요구 여부.

이 항목들은 ‘요건이 없다’는 뜻이 아니다. 공개 자료와 제공된 안내문만으로 확정할 수 없다는 뜻이다. 공식 선정 공지는 후속 공지가 이메일로 전달된다고 명시한다.
