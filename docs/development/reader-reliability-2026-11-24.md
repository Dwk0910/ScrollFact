# 문단 누락과 Gemini 503 조사 (2026-11-24)

## 문단 처리 경로

문단 분리는 AI 호출이 아니라 HtmlParser의 HTML 구조 처리다. p/li/blockquote 및 br 빈 줄로 문단을 나눈다. 기존에는 AI가 auxiliary로 분류한 문단을 AnalysisService가 삭제했다. 인용부호와 특정 종결 표현을 찾는 예외만으로는 일반 본문을 보호할 수 없어 이를 폐기했다.

이제 결과 API의 passages는 추출 목록과 순서를 그대로 보존한다. 신규 AI 출력 스키마는 body/opinion만 허용한다. 기존 auxiliary 응답도 버리지 않고 제목에 ‘원문 보존 · AI 해설 없음’을 표시해 원문으로 제공한다. 별도 AI 재분류 호출을 추가하지 않는다. 모든 ID를 반환했는지와 원문/근거 인용 검증은 유지한다. 기자 연락처만으로 구성된 줄은 추출 시 제외하며 이메일을 언급하는 일반 문장은 보존한다. 그림 확대 링크와 텍스트 없는 링크는 자료 수집 대상에서 제외해 불필요한 수집을 줄인다.

## 실제 측정

저장된 동일 키·gemini-3.5-flash-lite, 직접 generateContent. 키/원문/자유 형식 제공자 응답은 로그에 남기지 않았다. 기존 사용자 서버를 변경하지 않고 새 빌드와 암호화된 프로필 복사본을 사용한 격리 서버에서 테스트했다.

| 요청 | HTTP | 소요 시간 |
| --- | --- | --- |
| 최소 일반 요청 101bytes, 출력상한256 | 200 | 1410ms |
| 최소 JSON 스키마 요청 264bytes, 출력상한256 | 200 | 892ms |
| 최소 일반 요청 반복 | 200 | 1052ms |
| 전자신문 실제 분석 첫 시도 | 503 | 1299ms |
| 동일 기사 요청 재시도 (설정 변경 없음) | 200 | 7271ms |

일반/JSON 최소 요청에서는 Retry-After 및 확인한 요청 ID 헤더가 없었다. 실제 업로드→추출→Gemini→검증→결과 반환 전체는 10.37초. source0, 본문10, 제외0, 마지막 정우성 이사장 인용 포함. 입력2259/출력2911토큰. 분석 ID 3877caf1-d541-4f40-b43e-d7e33fa46c73, 제공자 요청 로컬 상관 ID 4eb0a635-5b0f-4b4f-b1b3-0cf676f18be5. Google 요청 ID라고 혼동하지 않는다.

최신 실제 결과의 1/6/10문단을 대조: 해요체, 사례별 신청까지 연결·제설제 시점과 양·학교명 및 마지막 발언 보존 확인. 전체 해설의 완전성이나 다른 사이트 전부를 보장하지 않는다.

## 해석과 제약

이번 결과는 고정된 잘못된 API 키/JSON 형식보다는 일시적인 제공자 처리 불가와 부합한다. 동일 요청이 변경 없이 503→200이었다. 그러나 Google 내부 용량/라우팅/프로젝트별 원인은 이 측정만으로 확정할 수 없다. 최소 요청 성공만으로 큰 요청의 안정성을 보장할 수 없다. 과금 변경·키 재발급·다른 모델 자동 호출을 해결책으로 단정하지 않는다.

503 최대3회 제한은 유지한다. 매 시도 HTTP/소요시간/로컬 상관 ID를 기록하고, 마지막 오류의 high demand/overload/capacity 문구를 고정 enum으로 분류해 기록한다. 제공자의 자유 텍스트나 키를 로그에 저장하지 않는다.

공식 포럼의 동일 모델·동일 요청 간헐 실패 사례(5회 중 1회 성공)와 서비스 과부하 안내 답변:
- https://discuss.ai.google.dev/t/intermittent-http-503-from-generatecontent-with-gemini-3-5-flash-lite/201338
- https://discuss.ai.google.dev/t/intermittent-http-503-from-generatecontent-with-gemini-3-5-flash-lite/201338/2

별도 AI 호출 없이 모든 추출 문단을 보존하는 API 회귀, 일반 문단 오분류, 마지막 인용, 연락처 줄 및 전자신문 실제10문단 회귀 검사와 backend:test/bootJar 통과. HTML 후보 자체가 모든 사이트에서 완전한지는 별도 과제다. 소스 본문에 섞인 애매한 부가정보도 AI가 임의로 삭제하는 대신 남기는 선택이다.
