⑥ 핵심 기능 · 화면

① 글 맥락 분석
문단별 해설로 글의 주장과 흐름을 읽습니다. 문장별 분석에서 판단과 근거 출처를 확인하고, 원문과 해설에 표시된 재확인이 필요한 표현을 살펴봅니다.

사진 안의 번호와 설명 대응
1. 문단별 해설로 글의 주장과 흐름을 읽기 → 3문단 원문과 연결된 3문단 해설
2. 문장별 분석 표시 → ‘자료와 일치’ / ‘확인 자료 부족’ 판단 표시
3. 근거 확인 → 펼쳐진 근거 출처 이름과 인용 내용
4. 재차 확인할 부분 → 원문과 해설의 노란 표시 및 자료 부족 이유
사진 위와 아래는 같은 3문단의 실제 UI입니다. 위는 본문과 해설, 아래는 ‘이 문단을 살펴보면’과 ‘근거 출처’를 펼친 부분입니다. UI 요소의 내부 배치를 새로 만들지 않았습니다.
다섯 분류 중 이 문단에 실제 해당하는 두 분류가 표시됩니다. 모든 문장을 다섯 색으로 임의 표시하지 않았습니다.

② 관점 파악
글 전체의 의견 분포를 게이지로 살펴보고, 관점별 발언을 펼쳐 각 사람이 밝힌 이유를 읽습니다. ‘원문 위치’를 누르면 해당 의견의 원문으로 이동합니다.

사진 안의 번호와 설명 대응
1. 글 전체 의견을 관점별로 살피기 → 전체 의견 게이지와 펼친 관점
2. 그렇게 생각하는 이유 읽기 → 작성자가 밝힌 경험과 이유
3. 작성한 원문 확인 → ‘원문 위치’ 링크
사진에는 원문으로 이동하는 링크가 보이며, 이동 후 화면까지 한 화면으로 합성하지 않았습니다.
