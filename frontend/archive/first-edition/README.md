# ScrollFact 최초 UI 보관본

`241eaf9` 커밋의 프론트엔드 UI 소스를 그대로 추출했다. `0275a21`은 Vite 기본 템플릿이므로 제품 초판으로 분류하지 않았다. 실행 진입점은 `/first-edition.html`이다.

현재 확장앱의 background/content script는 교체하지 않는다. 브라우저 미리보기에서 기존 샘플 문단과 이전/다음 버튼으로 시연한다. 당시 로그인 버튼은 남아 있으나 확장 환경과 인증 설정이 필요하므로 코칭 시연 범위에서 제외한다. 요약 로직과 mock 데이터의 원래 위치도 역사적 비교를 위해 보존했다.

이 보관본은 최신 API와 연결하지 않으며, 최초 UI 자체를 현대화하거나 현재 구현처럼 표시하지 않는다.
