ScrollFact

서버 준비가 끝났어요. 브라우저에 확장을 설치하면 시작할 수 있어요.

확장 프로그램 내려받기
  1. ZIP을 고정된 폴더에 압축 해제하세요. 업데이트할 때도 같은 폴더를 사용하세요.
  2. Chrome은 chrome://extensions, 웨일은 whale://extensions, Edge는 edge://extensions를 열어요.
  3. 개발자 모드 → 압축 해제된 확장 프로그램을 로드에서 manifest.json이 있는 폴더를 선택하세요.
  4. 기사 페이지에서 ScrollFact를 열고 설정 → 계정에 사용할 ID를 입력하세요.
  5. AI 연결에서 API 키를 입력하고 모델을 선택해 저장하세요. 다른 컴퓨터의 키는 자동으로 옮겨지지 않아요.
  6. 기사에 댓글이 있다면 먼저 불러온 뒤 이 페이지 분석하기를 누르세요.

기본 서버 주소는 http://127.0.0.1:8080이에요. Docker 포트를 바꿨다면 확장 설정의 서버 주소도 바꿔 주세요.

서버를 끄려면 저장소에서 docker compose down. 계정·키 설정은 Docker 볼륨에 남아요.
